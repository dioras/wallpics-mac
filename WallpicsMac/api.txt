Introduction
Base URL: https://backend.wallpics.app

This documentation aims to provide all the information you need to work with our API.
As you scroll, you'll see code examples for working with the API in different programming languages in the dark area to the right (or as part of the content on mobile). You can switch the language used with the tabs at the top right (or from the nav menu at the top left on mobile).

Authentication
All API requests must include the following headers:

    x-auth: Must be set to the current Unix timestamp (PHP: time()).
    x-token: Must be the MD5 hash of the current timestamp concatenated with the string "wall" (PHP: md5(time() . "wall")).

In the API examples the header values are pre-computed, but you should compute them at a request time.
Ensure your client correctly calculates these values before making requests.

Guest ID
For better user experience you should provide a X-Guest-Id HTTP header with each request. You should obtain the guest ID from the server. There's 2 ways to get it:

    Make a GET request to the /api/init-guest API endpoint.
    Provide a X-Get-Guest-Id header to any API endpoint.

In the response you will get X-Guest-Id header, which will contain the guest ID. You should store this ID and provide to all next requests to the API.
In case you're using /api/init-guest - guestId will be also provided in the response.
Authenticating requests

To authenticate requests, include an Authorization header with the value "Bearer {YOUR_AUTH_KEY}".

All authenticated endpoints are marked with a requires authentication badge in the documentation below.

You can retrieve your token by logging in using /api/auth/request-code endpoint.
Auth management
Get guest ID

X-Guest-Id header and guestId field with the guest ID value will be returned.

    Example request:

const url = new URL(
    "https://backend.wallpics.app/api/init-guest"
);

const headers = {
    "Content-Type": "application/json",
    "Accept": "application/json",
    "x-auth": "1770914110",
    "x-token": "5a0aa41e5e62dabd28fee1fb1292bfc8",
    "x-guest-id": "c7b22624-95a6-49f4-bc03-d33f4f2d39d5",
    "x-get-guest-id": "1",
};

fetch(url, {
    method: "GET",
    headers,
}).then(response => response.json());

Login with OTP

Authenticate using One Time Password code. Before calling this endpoint, you should call the api/auth/request-code to send the OTP code to user's email, so user can provide the code.

    Example request:

const url = new URL(
    "https://backend.wallpics.app/api/auth/verify-code"
);

const headers = {
    "Content-Type": "application/json",
    "Accept": "application/json",
    "x-auth": "1770914110",
    "x-token": "5a0aa41e5e62dabd28fee1fb1292bfc8",
    "x-guest-id": "c7b22624-95a6-49f4-bc03-d33f4f2d39d5",
    "x-get-guest-id": "1",
};

let body = {
    "device_name": "Nuno's iPhone 12",
    "email": "nels.kuhn@example.org",
    "code": 123456
};

fetch(url, {
    method: "POST",
    headers,
    body: JSON.stringify(body),
}).then(response => response.json());

Home screen

Contains all categories and covers with wallpapers inside. Also provides all available tags.
Pagination is used to limit wallpapers count in each category, cover and discover section.
The page parameter changes the page of each category. But to easily retrieve wallpapers from one particular category, you should use the wallpaper-list API endpoint.

    Example request:

    "https://backend.wallpics.app/api/home-screen"
);

const params = {
    "getChargeAnimationsCategory": "0",

    "per_page": "10",
